# Farmacia-Clientes
Sistema de gerenciamento de clientes com CRUD usando HTML, JavaScript e json-server

Farmacia-Clientes

Sistema web de gerenciamento de clientes (CRUD) desenvolvido com HTML, CSS, JavaScript e json-server, simulando uma API REST.

📌 Sobre o projeto

Desenvolvi este sistema para praticar consumo de API, manipulação do DOM e boas práticas em JavaScript puro, simulando um cenário real de cadastro de clientes para uma farmácia.

A aplicação permite:

Cadastrar clientes

Listar clientes

Buscar por nome

Excluir clientes

🧰 Tecnologias

HTML5

CSS3

JavaScript (Vanilla JS)

json-server (API REST simulada)

Fetch API

Async/Await

⚙️ Funcionalidades

CRUD completo (GET, POST, DELETE)

Renderização dinâmica com createElement

Eventos com addEventListener (sem onclick inline)

Validação básica de formulário

Filtro de clientes em tempo real

▶️ Como executar
npm install -g json-server
json-server --watch db.json --port 3000


Acesse:

http://localhost:3000/clientes


Depois, abra o arquivo index.html no navegador.
